Повторяемые команды из корня полного клона, после установки зависимостей:

```sh
python runtime/yado_full_kernel_audit_v1.py
python -m successor build --output /tmp/yado-successor-fresh-birth
python runtime/yado_full_regression_v1.py --manifest /tmp/yado-successor-fresh-birth/manifest.json
```

Каталог сборки должен быть новым. Неполная история Git, отсутствующий manifest,
пустой набор, пропущенный тест или изменение исходников во время проверки
блокируют PASS. Workflow выполняет эти этапы последовательно, сохраняет журнал
также при отказе и не переносит положительный отчёт на изменившийся `main` через rebase.

Включённые `api/index.py` и `vercel.json` описывают только HTTP-интерфейс статуса.
Они не запускают фоновый цикл Successor и не предоставляют постоянное хранилище.
Развёртывание работающего ядра требует отдельной среды с постоянным диском.
