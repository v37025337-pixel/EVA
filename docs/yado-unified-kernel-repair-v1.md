## Repairs

- Program repair distinguishes booleans from numbers and runs the bounded repair
  language in an isolated process with CPU, wall-time, memory and serialization limits.
- Candidate admission binds approvals to the exact parent and candidate; protected
  inherited capabilities and rollback copies survive successive promotions.
- OpenAPI transport pins validated IPs, preserves TLS hostname checks, ignores
  environment proxy settings and refuses redirects.
- API readiness returns 503 for invalid, missing or stale canonical/audit evidence;
  200 requires matching deployed source hashes.
- Original V3/V4 candidates and receipts remain historical evidence. Maintenance
  is recognized separately; historical V4 testing uses its recorded promotion commit.
