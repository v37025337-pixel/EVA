# EVA

YADO is an experimental, event-sourced cognitive kernel with verified experience,
native program synthesis and bounded development loops.

The [native program development guide](successor/PROGRAM_DEVELOPMENT.md) describes
the compositional generator, structured data tasks, verified program memory,
finite continuation commands and rollback. Grammar/controller improvements are
maintainer-authored; individual emitted programs are selected by the kernel.

The executing implementation is pinned by
`canonical/yado-unified-core-v1.json`, `canonical/yado-main-head-g2.json` and the
append-only evolution ledger. `main` is the integration line. Experiments retain
their actual PASS, FAIL and WITHHOLD evidence; they do not establish consciousness.
